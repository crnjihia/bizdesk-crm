🔒 AsyncLocalStorage Context

Every incoming web request wraps the server action with tenantContext.run(orgId, cb). Child services cannot bypass the tenant scope.

🛡️ Traversal Leak Proof

Direct queries by primary key (findUnique) are rewritten into findFirst with organizationId filter to eliminate IDOR vulnerabilities.

Production Database Schema (Prisma ORM)

Compound unique constraints, relational cascaded foreign keys, and organization scoping indexes.

prisma/schema.prisma PostgreSQL 
model Organization {
  id                   String        @id @default(cuid())
  name                 String
  slug                 String        @unique
  stripeCustomerId     String?
  stripeSubscriptionId String?
  plan                 String        @default("free")
  createdAt            DateTime      @default(now())

  memberships          Membership[]
  clients              Client[]
  invoices             Invoice[]
  activityLogs         ActivityLog[]
}

model Invoice {
  id             String        @id @default(cuid())
  organizationId String
  clientId       String
  number         String
  status         InvoiceStatus @default(draft)
  issueDate      DateTime      @default(now())
  dueDate        DateTime
  currency       String        @default("KES")
  total          Decimal       @default(0)
  mpesaRef       String?
  createdAt      DateTime      @default(now())

  organization   Organization  @relation(fields: [organizationId], references: [id], onDelete: Cascade)
  client         Client        @relation(fields: [clientId], references: [id], onDelete: Restrict)
  lines          InvoiceLine[]
  payments       Payment[]

  @@unique([organizationId, number])
  @@index([organizationId])
  @@index([clientId])
  @@index([status])
}
Enterprise Topology

Zero-Trust Multi-Tenant Architecture

How BizDesk CRM routes, authenticates, scopes, and reconciles financial data from client request to database query.

💻

1. Client / App Router

Next.js 14 App Router (/org/[slug]/*). Server Actions with optimistic UI states and toast triggers.

🛡️

2. RBAC & Tenant Context

Node AsyncLocalStorage wraps the request. requireRole(['owner', 'admin']) enforces member privileges.

⚙️

3. Prisma Middleware

Automatically intercepts queries, injecting where: { organizationId } to prevent cross-tenant traversal leaks.

🏦

4. PostgreSQL & Gateways

PostgreSQL with compound indices, Safaricom Daraja M-Pesa webhooks, Stripe billing, and Resend email delivery.

🇰🇪

M-Pesa Reconciliation Engine

Directly integrates with Safaricom Daraja STK Push and C2B transaction references. Auto-updates invoice status from Pending to Paid with zero manual data entry.

🛡️

Hard Multi-Tenancy Isolation

Zero-trust database isolation using Prisma ORM middleware and AsyncLocalStorage. Completely prevents cross-organization leaks even under adversarial queries.

📄

Instant Tax PDF Dispatch

High-fidelity PDF invoice rendering powered by @react-pdf/renderer with KRA PIN, 16% VAT breakdown, and direct Resend email delivery.

💳

Stripe Subscription Metering

Tiered SaaS plans (Starter, Pro, Enterprise) with hard quotas for active clients, monthly invoices, and team seats with idempotent webhook ingestion.

👥

Role-Based Access Control (RBAC)

Organization-level roles (Owner, Admin, Member) with declarative server action guards, preventing unauthorized invoice edits or team modifications.

📊

Audit Ledger & CSV Export

Detailed audit trail tracking all state mutations with actor ID and IP, plus one-click CSV export ready for Kenya Revenue Authority (KRA) filing.

Local Development

Get Started in 4 Steps

Spin up the PostgreSQL database via Docker Compose, apply Prisma migrations, and run the Next.js development server.

1

Clone Repository & Install Dependencies

Ensure Node.js 20+ is installed on your workstation.

Terminal 
git clone https://github.com/crnjihia/bizdesk-crm.git
cd bizdesk-crm
npm install
2

Configure Environment & Start PostgreSQL

Copy .env.example to .env and boot the PostgreSQL container.

Terminal 
cp .env.example .env
docker-compose up -d
3

Run Prisma Migrations & Seed Demo Kenyan Data

Generates the Prisma client, pushes database schema, and seeds realistic Kenyan SMEs and M-Pesa invoices.

Terminal 
npx prisma generate
npx prisma db push
npm run seed
4

Start Dev Server

Navigate to http://localhost:3000 to access the live CRM interface.

Terminal 
npm run dev
